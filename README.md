# BTS — Página Informativa

## Descrição

Este projeto consiste em uma página informativa sobre o grupo sul-coreano BTS.

A página apresenta informações sobre a história do grupo, seus integrantes,
músicas de destaque e algumas curiosidades.

O projeto foi desenvolvido como atividade acadêmica com foco na utilização
de HTML5, CSS3, Git, GitHub e GitHub Pages.

## Tema escolhido

O tema escolhido foi o BTS (Bangtan Sonyeondan), um grupo sul-coreano
formado por sete integrantes.

O conteúdo aborda:

- História do BTS
- Integrantes
- Músicas de destaque
- Curiosidades
- Fandom ARMY
- Estilos musicais

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Design

Foi utilizada uma paleta de cores baseada em tons de roxo, preto e branco,
criando uma identidade visual inspirada no universo do BTS.

O site também possui layout responsivo para dispositivos móveis,
tablets e computadores.
