## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de uma página informativa
sobre o grupo sul-coreano BTS.

A página apresenta informações sobre a história do grupo, seus
integrantes, carreira, conquistas, curiosidades e impacto cultural.

O projeto foi desenvolvido como atividade acadêmica para demonstrar
conhecimentos de HTML5 e CSS3, além da utilização do GitHub para
versionamento e publicação do site.

---

## 🎤 Tema escolhido

O tema escolhido foi o BTS (Bangtan Sonyeondan), grupo sul-coreano
formado por sete integrantes:

- RM
- Jin
- SUGA
- J-Hope
- Jimin
- V
- Jung Kook

## 📱 Características do site

O site possui:

- Layout responsivo;
- Menu de navegação;
- Cabeçalho;
- Conteúdo organizado em seções;
- Informações sobre os integrantes;
- Imagens com atributo `alt`;
- Lista de curiosidades;
- Lista de conquistas;
- Caixa de citação;
- Barra lateral;
- Rodapé;
- Efeitos `hover`;
- Layout utilizando CSS Grid;
- Compatibilidade com celulares, tablets e computadores.
